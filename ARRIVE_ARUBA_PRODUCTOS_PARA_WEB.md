## Notas Para El Desarrollador

- La web debe permitir que estos productos se carguen y editen desde Shopify sin codigo.
- Cada producto debe soportar variantes por color y talla.
- El selector de color debe usar swatches con los HEX oficiales.
- El selector de talla debe mostrar XS, S, M, L, XL y XXL.
- La pagina de producto debe mostrar los placements de bordado como informacion editorial o tecnica.
- El filtro de busqueda debe respetar los campos del PDF: color, categoria, marca, tipo de prenda, talla, condicion y ubicacion.
- Las fichas tecnicas reales aun tienen campos pendientes; no bloquear el desarrollo visual por esos campos.
- Los precios son ficticios y deben poder cambiarse desde Shopify.
